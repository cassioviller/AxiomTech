# Cássio Viller — portfólio e currículo

Site estático, currículo em PDF e folhas de caso. Plano e decisões em `PLANO.md`; como gerar e publicar em
`portfolio/README.md`.

- **Rodar:** o botão Run serve `portfolio/site/` na porta 5000 (`python3 -m http.server`).
- **Publicar:** deploy estático do Replit apontando para `portfolio/site/`, ou copiar essa pasta para qualquer hospedagem.
- **Regenerar PDFs:** `portfolio/build.sh`.

A pasta `axiom/` (site institucional da Axiom, React + Express) está fora do git — ver `.gitignore`.
